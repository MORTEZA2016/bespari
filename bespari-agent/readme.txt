اتصال سایت بازاریاب به سایت مادر بسپاری ERP — ارسال خودکار سفارش‌ها و دریافت قیمت/موجودی.

== Description ==

این افزونه روی سایت بازاریاب نصب می‌شود و به سایت مادر (بسپاری ERP) متصل می‌شود:

* ارسال خودکار سفارش‌های ووکامرس (Push) هر ۵ دقیقه با صف و retry (حداکثر ۵ تلاش)
* دریافت قیمت و موجودی محصولات (Pull) هر ۳۰ دقیقه و اعمال روی ووکامرس
* احراز هویت HMAC-SHA256 با API Key + Secret (از سایت مادر دریافت کنید)
* دوبل‌نشدن سفارش‌ها با external_ref (idempotent)
* تست اتصال handshake از صفحه تنظیمات

== Installation ==

1. افزونه را روی سایت بازاریاب نصب و فعال کنید.
2. از منوی «بسپاری Agent» آدرس سایت مادر + API Key + Secret را وارد کنید (کلیدها را ادمین سایت مادر از صفحه «اتصال‌ها» بسازد).
3. دکمه «برقراری ارتباط آزمایشی» را بزنید.
4. تیک «فعال» را بزنید و ذخیره کنید.
